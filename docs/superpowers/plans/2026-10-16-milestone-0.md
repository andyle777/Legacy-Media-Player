# Milestone 0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Track results in the verification report.

**Goal:** A runnable and testable Windows-first media-player foundation.

**Architecture:** Core defines IPlaybackEngine. Application consumes it and owns
session presentation and the mock. LibVLC implements the contract; App composes
the engine and provides the desktop shell and native video host.

**Tech Stack:** C#/.NET 10, Avalonia 11.3.22, LibVLCSharp 3.10.2, xUnit 2.9.3.

**Spec:** [Design](../specs/2026-10-16-milestone-0-design.md).

## Global constraints

- Windows 10/11 x64 first; future Linux/Android; no macOS support.
- Keep UI/native dependencies out of Core and Application.
- Preserve existing work; implement in a separate empty clone on milestone-0-bootstrap.
- No native types in IPlaybackEngine; explicit mock selection.
- Commands are serialized; notifications may originate on background threads.

## Review focus

Missing files must preserve loaded media; invalid volume/seek must not corrupt
state; callbacks queued during shutdown must be ignored; missing native runtime
must be reported; switching media must release the old decoder. Pin these with
tests and native smoke verification where practical.

## Implementation decisions

- Use an independent empty clone in this task while preserving the original
  checkout. No main branch exists upstream yet, so remote CI/PR execution is
  deferred until publication is requested.
- Install .NET SDK 10.0.402 locally in the task's work folder; leave the existing
  machine-wide .NET 6 runtime unchanged.
- Use Avalonia.Win32/Skia 11.3.22 instead of the all-platform Desktop bundle.
  The first restore exposed a vulnerable unused Linux D-Bus dependency.
- Classify native end-with-no-duration-or-progress as no-playable-content and
  preserve terminal Failed/Ended through LibVLC's subsequent Stopped callback.
  This behavior was reproduced with the damaged-file native regression.
- Independent review found seek-thumb release events consumed by the control
  and missing Up/Down seek commits. Add headless UI tests, observe both fail,
  then register handled release events and complete keyboard handling.
- Store file-picker failures in session presentation state so playback
  notifications do not hide them. A new managed regression failed then passed.
